# 🚀 Krishna Mall - Personal Portfolio

A modern, interactive **3D personal portfolio website** for **Krishna Mall** — Computer Science Engineering student at Lovely Professional University (LPU), Punjab, India, passionate about game development, programming, and building interactive software experiences.

## ✨ Highlights

- **3D Interactive Character** powered by **Three.js** & WebGL
- High-performance dark futuristic aesthetic
- Cinematic scroll transitions & text animations with **GSAP** & **ScrollTrigger**
- Smooth inertial scrolling with **Lenis**
- Dedicated **Showcase of Projects** (Canteen, The Khao PiYo, AgriSense, Rescue Mash)
- Dedicated **Certificates Section**
- Dedicated **CV / Resume Page** with dual-pane PDF viewer and photo framing
- Fully responsive across desktop, tablet, and mobile devices

## 🧰 Tech Stack

- **React 18** + **TypeScript**
- **Three.js** + **@react-three/fiber** + **three-stdlib**
- **GSAP** + **ScrollTrigger**
- **Lenis** Smooth Scroll
- **React Router 7**
- **Vite**

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Run locally in development mode
npm run dev

# Build for production
npm run build
```
